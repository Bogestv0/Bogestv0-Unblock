# Bogestv0 Unblock

Программа для Windows, которая помогает открыть Discord и YouTube там, где их замедляют или блокируют.

## Как это работает
Программа перехватывает свои исходящие пакеты и слегка меняет способ отправки первого TLS-пакета (ClientHello),
чтобы оборудование провайдера (DPI) не распознало имя сайта: разрезает пакет на части, отправляет их в обратном порядке,
подмешивает «ложный» пакет с малым TTL / неверной суммой, для голоса Discord шлёт ложные UDP-пакеты, QUIC отключает
(браузер переходит на обычный TCP). Трафик не проксируется и не шифруется, остаётся прямым.

В окне есть **автоподбор**: программа сама перебирает 15 стратегий и выбирает ту, при которой сайты открываются.

## Установка
Скачайте `Bogestv0-Unblock-Setup.exe` из раздела Releases и запустите (нужны права администратора).
Установщик скачает драйвер WinDivert с официальной страницы автора и создаст ярлык.

## Сторонний компонент
[WinDivert](https://github.com/basil00/WinDivert) (LGPLv3 / GPLv2) — драйвер перехвата пакетов. В репозитории его нет,
скачивается при установке. Антивирус может на него ругаться — это штатное поведение таких драйверов.

## Честные ограничения
- Выбор программ работает для TCP/HTTPS; программа должна быть запущена до подключения.
- Если провайдер блокирует DNS (в проверке «DNS: имя не найдено»), обход пакетов не поможет — в окне есть кнопка «Исправить DNS».
- Только IPv4. Если у провайдера работает IPv6 — отключите его на адаптере или он обойдёт программу.
- ClientHello, разбитый на несколько TCP-сегментов, не обрабатывается.
- Результат зависит от провайдера: единой стратегии нет, для этого есть автоподбор.
- Голос Discord проверить автоматически нельзя — проверяйте звонком.
- Установщик не подписан: Windows SmartScreen покажет предупреждение («Подробнее → Выполнить в любом случае»).
- Версия не тестировалась на живом Windows с реальным драйвером — пришлите журнал из окна, если что-то не работает.

## Сборка
`bash build.sh` (Go 1.21+) → `dist/Bogestv0-Unblock-Setup.exe`. Релиз: тег `vX.Y.Z` → GitHub Actions соберёт и выложит.
Автор: [@bogestv0](https://t.me/bogestv0). Удаление — кнопка в окне программы («Удаление»). Переключатель «Всегда включён» — автозапуск в фоне без окна.

Свои сайты: окно → «Свои сайты». Программы: окно → «Программы» (обход для всех сайтов выбранной программы).
